# Wordflow v0.5.0

> Historical release record. This page describes the v0.5.0 transition and is
> not current architecture or an operational runbook.

The v0.5.0 release completed the rename from LDaCA Web App to LDaCA Wordflow
across Python, npm, Tauri, Rust, packaging, and documentation. It introduced
`polars-source-utils`, expanded multilingual tokenizer support, added CILogon
and LDaCA Data Portal integration, adopted a generated frontend API client,
reorganized frontend features, and substantially revised desktop process and
release automation.

At that point the root repository still included a separate DocWorkspace
submodule and the backend architecture used the earlier managers, endpoints,
token transport, and sidecar state described by that release. Those details
are preserved only as release history. The current architecture is documented
under `docs/architecture/`, and current operational procedures live under
`docs/runbooks/`.

The release also established coordinated version stamping and tag-driven
desktop/Python publication. The current six-surface registry and release flow
are documented in [Wordflow Release](../runbooks/wordflow-release.md).
