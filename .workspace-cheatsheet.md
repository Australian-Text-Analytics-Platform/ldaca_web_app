# npm Workspace Cheat Sheet

## Setup (First Time)

```bash
npm install        # Installs root + all workspace dependencies
```

## Development

```bash
npm run dev                # Frontend dev server (web)
npm run desktop:dev        # Desktop app (with hot reload)
```

## Building

```bash
npm run build              # Build frontend only
npm run prepare:all        # Build backend + frontend
npm run desktop:build      # Build desktop installer
```

## Workspace Commands

```bash
npm run -w frontend <cmd>  # Run command in frontend workspace
npm ls --workspaces        # List all workspace dependencies
```

## Common Tasks

```bash
# Test frontend
npm run test

# Lint frontend
npm run -w frontend lint

# Clean builds
npm run clean

# View package info
npm ls --workspaces --depth=0
```

## Adding Dependencies

```bash
# To root (e.g., shared tools)
npm install -D <package>

# To frontend workspace
npm install <package> -w frontend
# OR: cd frontend && npm install <package>
```

## Troubleshooting

```bash
# Clean reinstall
rm -rf node_modules frontend/node_modules package-lock.json
npm install

# Verify workspaces
npm ls --workspaces --depth=0
```
